# План подготовки к экзаменам

Минимальный планировщик на HTML, CSS и JavaScript. Один экзамен, равномерное распределение задач, localStorage.

## Запуск

Откройте `index.html` в браузере. Сервер и зависимости не нужны.

## Файлы

- `.gitignore`
- `index.html`
- `style.css`
- `script.js`

## Алгоритм

Задачи распределяются в исходном порядке от сегодняшнего дня до дня перед экзаменом. Базовая нагрузка — целая часть N / D, первые N % D дней получают по дополнительной задаче. Все задачи равны по трудоёмкости. Календарные дни рассчитываются без сдвигов часового пояса.

## Проверки

- 5 задач на 3 дня: 2, 2, 1.
- Проверить пустой ввод, прошедшую дату и день экзамена.
- Перезагрузить страницу и проверить сохранение.
- Проверить узкий экран и управление с клавиатуры.

## Будущие функции

1. Отметка выполненных задач.
2. Перераспределение с учётом сложности.

## История

История до подключения Git восстановлена по переписке. Промежуточные снимки реконструированы и могут отличаться в деталях от исходных файлов. Даты коммитов назначены с условным интервалом 3 минуты; они не отражают фактическое время разработки.
